# Circle-out 仿真模型

实现：`VIOFrontendSimulator`；分析场景名：`circle_out`。

## 轨迹与朝向

平台以半径 `R=5 m`、线速度 `v=1 m/s` 做匀速圆周运动，高度固定为 `1 m`：

```math
\omega=v/R,\quad
p(t)=[R\cos\omega t,\ R\sin\omega t,\ 1]^T,
\quad v(t)=[-v\sin\omega t,\ v\cos\omega t,\ 0]^T.
```

姿态随切向方向旋转；按当前相机轴约定，光轴主要朝圆周外侧。相机不断看到轨迹外围的
新点，特征 track 相对较短，适合检查频繁三角化、滑窗进出和一般转弯运动。

```mermaid
flowchart LR
  C((圆心)) --- P[平台沿半径 5 m 圆周运动]
  P -->|相机光轴主要向外| F[半径 8/10/12 m 的特征壳层]
```

## 特征点

特征点在以 `(0,0,1.5)` 为中心、半径 `8/10/12 m` 的三个球面带上随机分布，俯仰角
范围约 `[-30°,30°]`。这种布局既避免完全共面，又让很多点处在轨迹外侧。

## 主要验证目标

- 持续偏航下姿态、速度和位置耦合是否稳定；
- 短/中等长度 track 的多视图三角化成功率；
- clone 增广与移除后的协方差是否保持非负；
- Schur 鲁棒门控是否只少量介入而不会压制正常观测。

实际 GT/EST、特征点分布和三角化结果见 `out/report.html` 的详细页。
