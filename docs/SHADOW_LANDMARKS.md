# 影子 Landmark：原理、边界与使用建议

## 1. 定义

当前工程同时维护两套点位置：

- **主 Landmark**：`Landmark::position`，用于构造 ESKF 视觉残差并影响导航状态；
- **影子 Landmark**：`shadow_position/shadow_cov_position`，只做地图后处理和一致性评估。

“影子”不是新的图像特征，也不是复制一套前端跟踪。它复用同一条特征轨迹，但把点位置交给
一个不反馈导航状态的独立滤波器更新，因此可以观察“持久地图点若单独优化会怎样”，同时避免
实验性的点协方差直接污染主 ESKF 后验。

## 2. 单点 EKF

对世界系影子点 `p_s`，第 i 个 clone 位姿给出归一化像平面预测：

```text
z_hat = pi(R_wc^T (p_s-c_w))
r     = z-z_hat
```

在当前估计处线性化：

```text
r ≈ H_p delta_p_s + n_eff
S = H_p P_s H_p^T + R_eff
K = P_s H_p^T S^-1
p_s+ = p_s + K r
P_s+ = (I-KH_p)P_s(I-KH_p)^T + K R_eff K^T
```

最后一式是 Joseph 协方差更新，可在有限精度下更好地保持对称和半正定。

## 3. clone 位姿不确定度

影子点虽然不保存与导航状态的交叉协方差，但投影仍依赖 clone 位姿。当前实现把该不确定度
近似并入等效量测噪声：

```text
R_eff = R_image + H_x P_x H_x^T
```

这里 `P_x` 是对应 clone 的 6x6 位姿协方差。若只使用图像噪声，影子点会把不确定的相机位姿
当作真值，得到虚假偏小的 `P_s`。

## 4. 为什么不能反馈导航状态

完整联合状态应包含：

```text
P_joint = [P_xx  P_xs]
          [P_sx  P_ss]
```

当前影子实现只保存 `P_ss`，没有保存 `P_xs`。然而影子点由历史 clone 观测估计，天然与导航
状态相关。如果以后再用该点约束导航，却仍假设二者独立，就会重复使用历史信息，使滤波器
协方差过度收缩，NIS/NEES 失真，甚至在长时运行中发散。

因此当前影子点遵守两条硬边界：

1. 不修改 `Landmark::position`；
2. 不产生任何反馈到 ESKF 的残差。

## 5. 为什么默认 MSCKF 下不会提升轨迹精度

默认后端采用一次性 MSCKF 轨迹：轨迹达到丢失、窗口边界或长度上限后被消费并删除。同一批
像素观测不会再次进入后验。当前代码明确在 `schedulerConsumesTracksOnce()` 为真时跳过影子点
更新，所以：

- 影子点不会改变默认导航 RMSE；
- 不会改变默认状态协方差；
- 只在允许持久轨迹重复存在的实验后端中提供地图输出和一致性诊断。

## 6. 影子点什么时候有价值

适合：

- 比较“重三角化、Schur 回代、独立 EKF”对地图点误差的影响；
- 监测 Landmark NEES、95% 覆盖率和协方差是否过度自信；
- 在不承担导航风险的前提下验证自适应协方差膨胀、鲁棒核和地图后处理。

不适合：

- 直接提高当前默认 MSCKF 的位姿精度；
- 代替回环检测或全局 BA；
- 在没有交叉协方差建模时作为持久地图点反向约束导航。

## 7. 若要让持久点真正帮助导航

可选路线按实现成本从高到低并不完全等同于收益大小：

1. **完整 EKF-SLAM Landmark**：把少量点加入状态并维护 `P_xl/P_ll`，统计一致但状态规模增长；
2. **Schmidt-Kalman Landmark**：保留地图点及交叉相关性，但把地图点作为 nuisance state，
   通常不更新其均值，以降低计算量；
3. **MSCKF + 少量 SLAM 点混合**：大多数短轨迹继续结构消元，只挑长期、强视差、空间分布好的
   少量点进入持久状态；
4. **滑窗 BA/因子图**：直接在窗口内联合优化位姿、速度、偏置和点，并通过边缘化保留先验。

对本项目，优先建议第 3 条：保留当前已验证的一次性 MSCKF 主干，只增加受控数量的持久点，
更容易做逐步消融，也不会一次性改写整个后端。

## 8. 推荐实验

影子点本身应作为诊断基线，而不是精度开关。建议固定同一前端观测，至少记录：

- 导航 ATE/RPE、姿态 RMSE、NIS/NEES；
- 主点与影子点的 gauge 对齐位置误差；
- Landmark NEES 与 95% 覆盖率；
- 重复观测计数、被阻止计数和轨迹消费率；
- 在纯旋转、低视差、启停和旋转-平移切换场景中的分项结果。

只有当“持久点反馈”同时改善轨迹误差、没有显著恶化 NIS/NEES，并在长时退化场景中稳定，
才应考虑替换默认 MSCKF 配置。
