# 影子 Landmark：原理、边界与使用建议

## 1. 定义

当前工程同时维护两套点位置：

- **主 Landmark**：`Landmark::position`，用于构造 ESKF 视觉残差并影响导航状态；
- **影子 Landmark**：`shadow_position/shadow_cov_position`，只做地图后处理和一致性评估。

“影子”不是新的图像特征，也不是复制一套前端跟踪。它复用同一条特征轨迹，但把点位置交给
一个不反馈导航状态的独立滤波器更新，因此可以观察“持久地图点若单独优化会怎样”，同时避免
实验性的点协方差直接污染主 ESKF 后验。

## 2. 单点 EKF

对世界系影子点 `p_s`，第 i 个 clone 位姿给出归一化像平面预测：

```text
z_hat = pi(R_wc^T (p_s-c_w))
r     = z-z_hat
```

在当前估计处线性化：

```text
r ≈ H_p delta_p_s + n_eff
S = H_p P_s H_p^T + R_eff
K = P_s H_p^T S^-1
p_s+ = p_s + K r
P_s+ = (I-KH_p)P_s(I-KH_p)^T + K R_eff K^T
```

最后一式是 Joseph 协方差更新，可在有限精度下更好地保持对称和半正定。

## 3. clone 位姿不确定度

影子点虽然不保存与导航状态的交叉协方差，但投影仍依赖 clone 位姿。当前实现把该不确定度
近似并入等效量测噪声：

```text
R_eff = R_image + H_x P_x H_x^T
```

这里 `P_x` 是对应 clone 的 6x6 位姿协方差。若只使用图像噪声，影子点会把不确定的相机位姿
当作真值，得到虚假偏小的 `P_s`。

## 4. 为什么不能反馈导航状态

完整联合状态应包含：

```text
P_joint = [P_xx  P_xs]
          [P_sx  P_ss]
```

当前影子实现只保存 `P_ss`，没有保存 `P_xs`。然而影子点由历史 clone 观测估计，天然与导航
状态相关。如果以后再用该点约束导航，却仍假设二者独立，就会重复使用历史信息，使滤波器
协方差过度收缩，NIS/NEES 失真，甚至在长时运行中发散。

因此当前影子点遵守两条硬边界：

1. 不修改 `Landmark::position`；
2. 不产生任何反馈到 ESKF 的残差。

## 5. 两种“影子”必须区分

当前代码中存在两种目的不同的结构：

1. **独立影子地图**：`Landmark::shadow_position/shadow_cov_position`。它是旧的离线诊断路径，
   不保存 `P_xl`，所以永不反馈导航；
2. **影子候选池**：`SchurVINS::shadow_candidates_`。它保存少量候选点的独立位置分布和稳定性
   统计，只负责决定“是否值得晋升”。候选本身也不产生导航残差。

只有候选通过稳定性和几何质量检查、并在**当前有效 clone** 中重新建立正规方程后，才会进入
`persistent_landmarks_`。晋升后协方差矩阵显式追加 `P_xl/P_ll`，此时它才是可反馈导航的
EKF-SLAM Landmark。

因此，“影子候选”不是用一个独立点滤波器偷偷约束导航，而是一个严格的两阶段设计：

```text
候选筛选（允许近似、绝不反馈）
        ↓
当前滑窗内重新线性化和延迟初始化（维护完整相关性）
        ↓
少量持久点直接 EKF 更新（可反馈导航）
```

## 6. 默认混合后端

默认仍以一次性 MSCKF 为主：

- 绝大多数特征轨迹只消费一次，并通过 Schur 消去点变量；
- 最多保留 `persistent_landmark_budget_=20` 个持久点；
- 候选池容量为 200，满时优先淘汰质量最低、最久未见的候选；
- 持久点按 4×3 图像网格限额晋升，默认每格最多 2 个，避免所有点集中在同一区域；
- 持久点重复观测的像平面方差默认放大 64 倍，吸收长期 FEJ 线性化误差、前端相关性和
  未建模地图过程噪声；候选晋升协方差仍由当前轨迹的 Schur 延迟初始化给出；
- 纯旋转/低视差轨迹可先提供无深度旋转约束，深度观测继续等待平移基线。

这是一种“MSCKF + 少量 SLAM 点”的混合结构。它不改变默认一次性观测生命周期，也不会把
全部地图点加入状态导致协方差规模失控。

## 7. 轨迹几何质量评分

成功三角化后计算五个归一化分量：

```text
s_parallax = clamp((alpha_max-alpha_min)/alpha_span, 0, 1)
s_views    = clamp((N_obs-2)/8, 0, 1)
s_cond     = 1 / (1 + log10(kappa)/4)
s_reproj   = exp(-e_rmse/(3 sigma_uv))
s_uncert   = 1 / (1 + sigma_position)

s_geometry = 0.30 s_parallax
           + 0.20 s_views
           + 0.15 s_cond
           + 0.20 s_reproj
           + 0.15 s_uncert
```

其中：

- `alpha_max` 是最大三角化视差；
- `kappa` 是几何正规矩阵条件数；
- `e_rmse` 是归一化像平面重投影 RMSE；
- `sigma_position=sqrt(trace(P_ll)/3)` 是平均位置标准差。

默认晋升还要求观测数不少于 4、视差超过三角化门限 0.5°、条件数不超过 `1e6`、位置标准差
不超过 3 m，且总评分不低于 0.68。评分只用于调度和候选筛选，不直接缩放 MSCKF 残差，避免
把启发式分数混入概率模型。

## 8. 低视差延迟与无深度旋转约束

当轨迹因窗口边界或长度上限准备消费，但三角化状态是 `LowParallax`、`IllConditioned` 或
`ExcessiveUncertainty` 时，只要当前仍可见且未超过延迟上限，就暂不删除整条轨迹。滑窗照常
删除最老 clone 及其观测，剩余轨迹继续等待新的平移基线。

低视差不等于完全没有信息。纯旋转时，同一静态点满足：

```text
b_j ≈ R_cj,w R_w,ci b_i
r_R = B_j^T (b_j - R_cj,w R_w,ci b_i)
```

`B_j` 是与 `b_j` 正交的 3×2 切平面基，因此 `r_R` 是 2 维、与深度无关的旋转残差。默认
MSCKF 会对准备消费的低视差轨迹先尝试该约束。考虑到 R/N 误分类、IMU 旋转补偿误差和相邻
bearing 的相关性，默认只使用理论信息强度的 `0.02`；显式 RD-VIO 模式保持原始强度：

- 成功使用的两条像素观测会增加 `visual_update_count`；
- 若轨迹被延迟，后续深度 Schur 更新只使用尚未消费的观测；
- 若轨迹被删除，则该旋转约束计入本次一次性消费；
- 默认 MSCKF 不添加 RD-VIO 的零平移先验，也不切换到 RD-VIO 压窗策略。

## 9. 低视差轨迹摘要归档

轨迹已经丢失时不能继续保留其 Feature/Observation，因为对应 clone 可能马上被边缘化。当前实现
保存一个轻量摘要：

```text
{首帧 bearing、末帧 bearing、两帧相机位姿快照、时间、观测数、失败状态}
```

同一外部特征 ID 未来重新出现后，用历史首尾射线和当前射线求交：

```text
min_p sum_i ||(I-d_i d_i^T)(p-c_i)||^2
A = sum_i (I-d_i d_i^T)
b = sum_i (I-d_i d_i^T)c_i
p = A^-1 b
```

纯旋转时各 `d_i` 近似平行，`A` 的最小特征值接近 0，候选会被秩/条件数检查拒绝；出现平移
后，射线夹角增大，才可能生成新的影子候选。达到视差门限但暂时未通过条件数、正深度或重投影
检查时，归档以 0.25 s 间隔重试，避免在每张相机图像上重复执行同一失败三角化。

这个 3D 结果**只能用于候选筛选**。历史 pose 快照没有保存与当前状态的交叉协方差，若直接把
它写入导航量测，相当于把旧位姿当成真值，会产生虚假信息。正式晋升仍要求当前活跃轨迹在
当前 clone 窗口内成功三角化。

## 10. 影子候选一致性滤波

同一 ID 的新三角化结果视作候选 3D 伪量测：

```text
r = p_measurement-p_candidate
S = P_candidate+P_measurement
NIS = r^T S^-1 r
```

若 `NIS` 超过 3 自由度 99% 门限 11.34，则认为两次轨迹不一致：候选重置为最新结果，稳定计数
重新开始。通过门限时执行 Joseph 形式的独立点更新，并维护几何评分和 NIS 的指数滑动平均。

候选至少需要两次稳定证据。候选协方差不会直接复制到联合状态；它只决定是否允许进入下一步。

## 11. 延迟初始化与交叉协方差

当前活跃轨迹的联合正规方程为：

```text
[Hxx Hxl] [delta_x] = [gx]
[Hlx Hll] [delta_l]   [gl]
```

状态后验增量 `delta_x` 求出后，点增量通过回代得到：

```text
delta_l = Hll^-1 (gl-Hlx delta_x)
```

把局部 Landmark 参数到世界坐标的雅可比记为 `T`，则延迟初始化雅可比为：

```text
J_x = -T Hll^-1 Hlx
P_xl = P_xx J_x^T
P_ll = J_x P_xx J_x^T + T (R Hll^-1) T^T
```

其中第二项是给定导航状态后的条件点协方差。实现把新的 3 维 Landmark 追加到固定导航块之后，
并通过 `P_xx` 自动建立新点与已有持久点之间的间接相关性。clone 增广和 IMU 传播也同步维护：

```text
P_xl+ = F P_xl
P_clone,l = J_clone P_xl
```

## 12. 持久点直接 EKF 更新

当前关键帧再次观测到持久点时，构造联合雅可比：

```text
H = [0 ... H_clone ... 0 | 0 ... H_landmark ... 0]
S = H P H^T + R
K = P H^T S^-1
delta = K r
```

雅可比使用 clone 首次估计位姿和持久点晋升位置的 FEJ 副本；残差仍在当前名义状态计算。更新前
依次执行硬重投影门限、Huber 权重和 2 自由度卡方门控，协方差使用 Joseph 等价形式更新，再把
联合增量同时注入导航、clone 和持久点均值。

## 13. 状态机

```text
普通一次性轨迹
  ├─ 几何足够 ─→ MSCKF Schur 更新 ─→ 删除
  │                                  └─ 候选稳定且当前仍可见 ─→ 持久点晋升
  └─ 低视差
       ├─ 有纯旋转信息 ─→ 无深度旋转约束
       ├─ 当前仍可见   ─→ 延迟消费，等待平移
       └─ 已丢失       ─→ 保存轨迹摘要，删除原轨迹
                              └─ 同 ID 重现且形成基线 ─→ 更新影子候选
```

## 14. 统计与验证

`VinsAnalysis` 在 stdout、`summary.csv`、`scheduler_summary.csv` 和
`frame_policy_summary.csv` 中记录：

- 延迟轨迹数；
- 活跃/创建/复用/拒绝的轨迹摘要数；
- 候选池大小、候选更新与拒绝数；
- 持久点数量、晋升、直接更新与拒绝数；
- R/N 运动分类数和无深度旋转约束数。

HTML 报告的调度和帧策略表也显示旋转约束、归档复用和持久点更新。评估时必须同时检查 ATE、
RPE、NIS/NEES、负协方差计数和重复观测计数；不能只因为持久点数量增加就认为精度得到改善。

## 15. 默认参数长时回归

固定 100 s、600 点、MSCKF + Keyframe-only、2° 三角化门限，对比关闭全部混合功能的原始
MSCKF 与默认混合后端（20 个持久点、旋转信息尺度 0.02、持久点量测方差倍率 64）：

| 场景 | 原始 MSCKF 位置 RMSE / m | 默认混合后端 / m | 变化 |
|---|---:|---:|---:|
| Circle-out | 0.3443 | **0.3262** | -5.3% |
| Circle-in | 0.4179 | **0.3124** | -25.2% |
| Helix-3D | 0.2013 | **0.0867** | -56.9% |
| Stop-go | 0.6688 | **0.0604** | -91.0% |
| Rotation/translation | 8.4281 | **7.3984** | -12.2% |

五个场景均保持 `reused_observations=0`、`duplicate_observations_blocked=0`，说明改善没有通过重复
使用普通 MSCKF 像素样本获得。Rotation/translation 仍明显差于标准场景，表明当前轻量旋转因子
和少量持久点只能缓解退化，不能替代 RD-VIO 的预积分拼接、前端鲁棒估计或完整滑窗 BA。
