# 相机坐标系问题诊断

> 历史归档：本文记录早期调试过程，代码位置、默认参数和部分结论可能已过时；当前实现请以 `docs/README.md` 及专题文档为准。

## 问题现象

大量特征点深度为负值（-90米），导致程序崩溃。

## 根本原因

**坐标系不匹配**：

### 当前设置

**机体坐标系（FRD - Forward Right Down）**：
- x轴：前（沿切线，运动方向）
- y轴：右（向上，-z_NED）
- z轴：下（径向向外，相机应该朝这个方向看）

**相机坐标系（OpenCV标准）**：
- x轴：右
- y轴：下
- z轴：前（光轴）

**外参设置**：
```cpp
ExtState ext_;
Quat q_ic = Quat::Identity();  // 相机和IMU重合
Vec3 t_ic = Vec3::Zero();
```

## 问题分析

如果 `q_ic = Identity`，则：
- 相机x = 机体x（前）❌ 应该是右
- 相机y = 机体y（右）❌ 应该是下
- 相机z = 机体z（下/径向外）✓ 这个对了

**相机坐标系需要旋转90度**！

## 解决方案

### 方案1：设置正确的外参（推荐）

机体系到相机系需要旋转：
- 机体x（前）→ 相机y（下）❌ 不对
- 机体y（右）→ 相机x（右）✓
- 机体z（下/径向外）→ 相机z（前/光轴）✓

实际上需要：
- 相机x（右）= 机体y（右）
- 相机y（下）= ?
- 相机z（前）= 机体z（下/径向外）

等等，我们的机体定义本身就有问题！

## 重新分析

让我重新理清楚：

### 目标

1. **相机光轴（相机z轴）要指向径向外侧**
2. 特征点在半径8-12m的圆环上
3. 轨迹在半径5m的圆周上

### NED世界坐标系

- x: North
- y: East
- z: Down（重力方向）

### 圆周运动（angle=0时）

- 位置：(5, 0, 1) = 在East侧，地下1m
- 径向向外：(1, 0, 0) = 指向East
- 切线方向：(0, 1, 0) = 指向North

### 如果相机光轴要指向径向外

**标准相机坐标系（OpenCV）**：
- x: 右
- y: 下
- z: 前（光轴）

**相机z轴 = 径向向外 = (1, 0, 0)（angle=0时）**

那么相机的姿态（在NED中）应该是：
- 相机z轴（前/光轴）= 径向向外 = (cos(angle), sin(angle), 0)
- 相机y轴（下）= NED的Down = (0, 0, 1)
- 相机x轴（右）= y × z = (0,0,1) × (cos,sin,0) = (-sin, cos, 0) = 切线方向

**这正好是机体姿态**！如果：
- 机体x = 相机z（光轴）
- 机体y = 相机x（右）
- 机体z = 相机y（下）

这需要外参旋转90度。

## 正确的外参

从机体系到相机系的旋转：
```
[相机x]   [0  1  0] [机体x]
[相机y] = [0  0  1] [机体y]
[相机z]   [1  0  0] [机体z]
```

即：
- 相机x = 机体y
- 相机y = 机体z
- 相机z = 机体x

这对应的旋转矩阵是绕y轴转90度：
```cpp
// 从机体到相机的旋转（ZYX欧拉角：0, -90度, 0）
Eigen::AngleAxisd rotation_vector(-M_PI/2, Eigen::Vector3d(0, 1, 0));
ext_.q_ic = Eigen::Quaterniond(rotation_vector);
```

或者直接构造旋转矩阵：
```cpp
Eigen::Matrix3d R_bc;
R_bc << 0,  1,  0,
        0,  0,  1,
        1,  0,  0;
ext_.q_ic = Eigen::Quaterniond(R_bc);
```
