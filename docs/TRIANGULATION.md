# 多视图特征点三角化

`SchurVINS::updateVisual` 不再使用仿真特征点真值初始化 `Landmark::position`。真值仅在
`enable_logging_=true` 时写入离线分析日志，不参与三角化、门限判断或视觉后验。

## 坐标与观测模型

关键帧保存 IMU 到世界的姿态 `R_wi` 和 IMU 世界位置 `p_wi`；外参 `R_ic/t_ic`
表示相机到 IMU。因此：

```text
R_wc = R_wi R_ic
p_wc = p_wi + R_wi t_ic
d_c  = R_wc^T (p_w - p_wc)
z    = [d_c.x / d_c.z, d_c.y / d_c.z]
```

观测 `Observation::un_pt` 是归一化像平面坐标 `(u,v,1)`，不能把像素方差直接当成
归一化坐标方差。仿真约为 `1 pixel / fx = 0.0054`，对应配置
`triangulation_uv_std=0.0054`。

## 初始化流程

1. 收集滑窗中有效关键帧观测，计算相机中心和世界系单位视线。
2. 用射线最小二乘获得初值：

   ```text
   Σ(I-d_i d_i^T) p_w = Σ(I-d_i d_i^T) p_wc_i
   ```

3. 检查最大视差、射线 Hessian 条件数和有限性。默认要求最大视差至少 5°。
4. 最多执行 5 次鲁棒 Gauss-Newton 重投影优化。残差先按协方差白化，再使用
   Huber 权重抑制异常观测。
5. 检查正深度、重投影 RMSE、信息矩阵条件数和最大位置标准差。
6. 只有成功点才进入 Schur/QR 后验；失败点等新增关键帧观测后再试。

5°门限是当前仿真下精度与等待时间的折中。2°门限虽然更早提供点，但初始化误差
中位数约 0.37 m；5°门限降至约 0.23 m，同时轨迹位置 RMSE 从约 0.0701 m 改善到
约 0.0692 m。真实相机应根据焦距、像素噪声、目标距离和运动基线重新标定。

## 初始协方差

每个观测的残差协方差近似为：

```text
S_i = σ_uv² I + J_pose_i P_rel_i J_pose_i^T
P_rel_i = P_ii + P_aa - P_ia - P_ai
```

`a` 是最老观测锚点。使用 clone 交叉协方差构造相对位姿协方差，能抵消全局平移、
旋转等共同不确定模态；直接把各帧绝对边缘协方差当成独立噪声，会严重重复计数。
最终 landmark 条件信息和协方差为：

```text
Λ_l = Σ J_l_i^T S_i^-1 J_l_i
P_l|a = max(1, χ²/dof) Λ_l^-1
```

由于 `Landmark::position` 存在世界坐标系中，还需传播锚点绝对位姿不确定度：

```text
P_l,world ≈ P_l|a + G_a P_aa G_a^T
G_a = [-hat(p_l-p_a), I]
```

三角化质量门限只检查 `P_l|a`，避免全局 gauge 不确定度把几何可靠点拒绝掉；保存到
`cov_position` 的则是 `P_l,world`。这是相对锚点条件下的工程近似。完整模型应构造
所有重投影残差的联合协方差，并
保留 landmark 与滑窗位姿之间的交叉协方差；当前独立 `Landmark::cov_position`
没有这些交叉块。这里使用相对协方差可避免明显的共同模态重复计数，同时保持每点
只涉及小矩阵运算。

## 失败状态与开销控制

日志区分：有效观测不足、视差不足、病态、负深度、重投影误差过大和不确定度过大。
`last_triangulation_obs_count` 保证相同观测集合只尝试一次。视差不足通常在射线求解前
退出，因此等待更多关键帧的成本很低。

100 s、1000 个仿真点的 5°门限测试中：

| 指标 | 结果 |
|---|---:|
| 三角化尝试 / 成功 | 13973 / 3176 |
| 尝试耗时中位数 / P95 | 0.5 μs / 3.4 μs |
| 三角化累计耗时 | 约 15 ms |
| 初始化误差中位数 / P90 | 0.229 m / 0.691 m |
| 最终误差中位数 / P90 | 0.134 m / 0.453 m |
| 后续修正改善率 | 91.4% |
| 初始 landmark NEES / 3 | 0.011（明显保守） |

累计耗时包含大量在视差检查处快速退出的尝试；它相对整个视觉后验开销很小。
NEES 偏小与全局 ESKF 的 NEES/NIS 结论一致，主要反映当前 `uv_var=400` 和状态
协方差配置过于保守，不应为了让单条仿真 NEES 接近 1 而在三角化中硬裁剪协方差。

## 报告输出

`VinsAnalysis` 生成 `out/triangulation_<tag>.csv`，记录失败原因、视差、条件数、
重投影 RMSE、耗时、初始/最终/真值位置、初始协方差、NEES 和修正次数。
`VinsReport` 在 `out/report.html` 中展示：

- 成功率、初始化与最终误差、单次耗时；
- 初始化误差对最终误差的双对数散点图；
- 视差对初始化误差的关系；
- 失败原因、初始协方差 NEES 和累计耗时。
