# Circle-in 仿真模型

实现：`VIOFrontendSimulator1`；分析场景名：`circle_in`。

## 轨迹与朝向

平台以半径 `R=10 m`、线速度 `v=1 m/s` 做匀速圆周运动，高度固定为 `1 m`。位置与速度
公式和 Circle-out 相同，只是半径更大、角速度更低。相机光轴朝向圆心附近，使同一批内圈
特征能被长时间跟踪。

```mermaid
flowchart RL
  P[平台沿半径 10 m 圆周运动] -->|相机光轴向内| F[半径 3/5/7 m 的内圈特征]
  F --- C((圆心))
```

## 特征点

特征点位于以 `(0,0,1.5)` 为中心、半径 `3/5/7 m` 的柱状/环状体中，竖直范围随半径
展开。与 Circle-out 相比，track 更长、同一 landmark 参与的关键帧更多，Schur 消元更
充分，但重复使用相邻时刻观测也会让统计样本相关性更强。

## 主要验证目标

- `VIOFrontendSimulator1` 的坐标轴/光轴约定是否与后端一致；
- 长 track 下 Hll 的深度弱方向和 LDLT 跳过策略；
- 重复滑窗观测下 `uv_var` 是否过小、后验是否过度自信；
- inward-looking 几何对三角化精度的改善。

该场景对视觉噪声权重较敏感，因此参数选择不能只以它的最低 RMSE 为准，必须结合启停和
三维轨迹的最坏误差共同判断。
